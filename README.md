# Dadyaran Lawyer Directory — Frontend Design

نمونه آزمایشی رابط کاربری دایرکتوری وکلای دادیاران؛ **فعلاً فقط طراحی فرانت‌اند** و بدون اتصال به وردپرس.

## مشاهده آنلاین

**[پیش‌نمایش GitHub Pages](https://amiirmahdi.github.io/dadyaran-directory-design/)**

## فناوری

- Tabler UI (CDN) + CSS اختصاصی
- HTML / CSS / Vanilla JavaScript
- فارسی، RTL و Mobile-first
- اطلاعات وکلا کاملاً آزمایشی؛ هیچ خدمت حقوقی واقعی در این پروژه ارائه نمی‌شود

## فایل‌های نسخه اولیه

- `index.html`: صفحه نمونه جستجو و نتایج وکلا
- `assets/css/design.css`: سبک بصری و طراحی واکنش‌گرا
- `assets/js/app.js`: جستجو، فیلترها، کارت‌ها، مقایسه و پاپ‌آپ

## سند مرجع پروژه

**[سند محدوده طراحی، تصمیمات و چک‌لیست تأیید](docs/DESIGN-BRIEF.md)**

تغییرات روی همین مخزن انجام می‌شوند. ابتدا صفحات با داده آزمایشی طراحی و تأیید می‌شوند؛ بعداً می‌توان طراحی را به قالب‌های PHP در افزونه مستقل وردپرس منتقل کرد. این پروژه به Elementor متکی نیست.

## انتشار

GitHub Pages: `Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)`.

هر تغییر روی شاخه `main` به‌صورت خودکار در پیش‌نمایش منتشر می‌شود.
